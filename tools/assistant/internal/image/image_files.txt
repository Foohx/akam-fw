# Single source of truth for the Akam files that go into the firmware image.
#
# make_kit.sh reads this list to build the kit's overlay/ and patches/; tests/kit_test.sh
# builds an image with src/ak_rtsp/build_firmware.sh and fails when the image and this
# list disagree (paths, modes, links), so the two code paths cannot drift apart.
# Binaries (bin/ak_rtsp, bin/dropbearmulti) and licences (local/akam/LICENSE.*) are
# built from variables in both scripts and are covered by the same test.
#
# Format, fields separated by one space:
#   file <mode> <kit path> <image path> <source in the repository>
#   link <target> <kit path> <image path>
